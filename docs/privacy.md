# NxLauncher 隐私与本地数据边界

NxLauncher 是本地启动器和打包工具。公开包不包含游戏、主机密钥、存档或发布者个人配置；用户自行选择的游戏目录和密钥只应留在本机。发布脚本不会把这些路径复制到应用、ZIP、SHA 或依赖清单。

运行时可能需要访问用户显式选择的游戏工作区、用户提供的 `prod.keys` 和本机工具链。它们用于本地转换/构建，不是发布材料。日志和诊断可能显示用户选择的路径；分享日志前请删除路径、标题 ID、密钥名和个人文件名。

发布 staging 目录不得放入游戏目录、`keys/`、存档、`.nsp`/`.xci`/`.nca` 文件、私钥、配置令牌或调试符号。审核脚本只检查 staging 和本地可达 Git 历史，不会读取游戏目录来“帮忙排除”。

默认字体为带 SIL OFL 许可的 Noto Sans SC 和自有程序化按钮字形。发布脚本不复制 `/System/Library/Fonts`、用户字体目录或任何商业字体。`NXLAUNCHER_FONT_PATH` 仅适合用户本地显式提供；由该字体生成的产物不应公开分发，除非用户另行取得许可。

macOS 签名会记录开发者证书身份，但不包含 Apple 账户、Keychain 密码或公证凭据。预览包的默认签名状态是 Developer ID hardened runtime、未公证、未 staple；公证必须由有明确授权和凭据的发布者单独执行。

发现真实密钥或游戏材料进入 Git 历史时，发布必须阻断：立即撤销/轮换密钥，由仓库所有者决定历史清理。没有凭据的旧开发绝对路径属于警告；发布当前包时仍必须移除。
